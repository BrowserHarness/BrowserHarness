# BrowserCrew Operating Model

## Development loop
UNDERSTAND → ROUTE TO CANONICAL OWNER → CHECK CURRENT STATE → CHECK EXISTING WORKFLOW/SKILL → VERIFY EXTERNAL STATE → PROPOSE → VALIDATE → APPROVAL IF REQUIRED → EXECUTE → RE-READ/VERIFY → EVALUATE → CAPTURE EVIDENCE → UPDATE OWNER → UPDATE PROGRESS-MEMORY.

## Runtime learning loop
GOAL → RECALL → PLAN → OBSERVE → EXECUTE → VERIFY → REFLECT → LEARN → MEMORY → CANDIDATE IMPROVEMENT → EVALUATE → PROMOTE.

## Rules
- Machine-readable state is authoritative where practical.
- Learned behavior remains inspectable/versioned.
- Reuse before reinvention.
- Evidence, not optimism, earns autonomy.
